# 故障案例复盘（Incidents）

> 每条一个 `##` 小节，记录一次真实感故障的时间、现象、根因、处置与复盘结论，用于相似症状的快速召回。

## INC-001 磁盘被日志写满导致服务不可用
- 时间: 2025-03-12
- 现象: 订单服务大量 500，日志报 No space left on device，/var 分区使用率 100%
- 根因: 应用日志未切割，单个文件涨到 80G，日志级别误开为 DEBUG 后写入量翻倍
- 处置: 用 truncate -s 0 清空目标日志恢复写入；配置 logrotate 每日切割保留 7 天；补充磁盘使用率告警
- 复盘: 监控缺少磁盘水位告警；日志策略未纳入上线检查项；DEBUG 级别变更未走审批
- 标签: disk,log,incident,production

## INC-002 OOM 导致订单服务重启循环
- 时间: 2025-04-08
- 现象: 订单服务每 20 分钟重启一次，监控显示 RSS 持续上涨，日志无异常栈
- 根因: 本地缓存未设置容量上限，按用户维度缓存订单列表，大促期间用户量翻倍后堆内存耗尽
- 处置: 临时扩容堆内存并重启；将本地缓存改为带容量上限的 Caffeine 并设置过期；补充堆内存与 GC 告警
- 复盘: 容量评估只按日常流量；缓存无上限属于常见隐患，需纳入代码评审清单
- 标签: memory,oom,java,incident

## INC-003 nginx 502 源于上游连接池耗尽
- 时间: 2025-04-21
- 现象: 网关大量 502，nginx error.log 报 connect() failed (111: Connection refused)，上游实例 CPU 不高
- 根因: 上游服务连接池上限设置过小，且存在连接未归还的缺陷，流量上涨后连接池被占满并拒绝新连接
- 处置: 重启上游实例恢复；修复未归还连接的代码；按压测结果调整连接池并增加池等待监控
- 复盘: 只监控了实例存活，没有监控连接池使用率；压测未覆盖连接泄漏场景
- 标签: nginx,502,connection,incident

## INC-004 MySQL 主从延迟导致读到旧数据
- 时间: 2025-05-09
- 现象: 用户下单后立即查询订单详情显示不存在，刷新几次后又正常，持续约 10 分钟
- 根因: 主库执行大批量归档删除形成大事务，从库单线程回放，Seconds_Behind_Master 涨到 300 秒以上
- 处置: 读流量临时切回主库；拆分归档批次并限制单批行数；从库开启并行复制并补充延迟告警
- 复盘: 归档脚本未评估主从延迟；读写分离缺少延迟阈值自动摘除
- 标签: mysql,replication,latency,incident

## INC-005 证书过期导致小程序全部请求失败
- 时间: 2025-06-18
- 现象: 小程序所有 HTTPS 请求失败，客户端提示证书已过期，服务端日志无请求记录
- 根因: 负载均衡上的证书未纳入统一管理，续签后只更新了源站 nginx，未同步到负载均衡
- 处置: 紧急替换负载均衡证书并验证证书链；建立证书清单与到期前 30 天告警；续签流程增加双端核对
- 复盘: 证书存在两处副本且无清单；到期监控只覆盖了源站
- 标签: certificate,tls,https,incident

## INC-006 误改 sudoers 导致全员无法提权
- 时间: 2025-07-03
- 现象: 运维人员执行 sudo 报 syntax error near line 58，所有提权操作失败，自动化任务中断
- 根因: 手工编辑 /etc/sudoers 时漏写逗号，且未使用 visudo 校验，配置语法错误使 sudo 拒绝加载
- 处置: 通过已登录的 root 会话恢复备份文件；使用 visudo 重新编辑并校验；补充配置变更双人复核
- 复盘: 直接编辑认证类配置风险极高；应默认使用 visudo 与配置管理工具下发
- 标签: sudo,permission,change,incident

## INC-007 定时任务并发执行导致重复扣款
- 时间: 2025-07-25
- 现象: 财务对账发现同一批订单出现两笔扣款，时间相差不到 1 秒
- 根因: 定时任务执行时间超过调度间隔，上一轮未结束时下一轮已启动，且扣款逻辑没有幂等键
- 处置: 紧急冲正重复扣款；为任务加分布式锁并设置超时；扣款接口增加业务幂等键
- 复盘: 调度配置未考虑任务时长；关键资金操作缺少幂等设计
- 标签: cron,idempotency,payment,incident

## INC-008 TIME_WAIT 过多导致新连接失败
- 时间: 2025-08-14
- 现象: 短连接服务偶发 Cannot assign requested address，ss 统计 TIME_WAIT 超过 5 万
- 根因: 服务每次请求新建 HTTP 连接且不复用，本地端口范围耗尽后无法发起新连接
- 处置: 改为连接池并开启 keep-alive；客户端开启 tcp_tw_reuse；扩大本地端口范围并观察
- 复盘: 连接池未作为默认规范；短连接压测未覆盖端口耗尽场景
- 标签: tcp,timewait,connection,incident

## INC-009 Redis 内存满触发淘汰导致缓存击穿
- 时间: 2025-09-05
- 现象: 商品详情接口 RT 从 20ms 涨到 800ms，数据库 QPS 突增，Redis 报 OOM command not allowed
- 根因: 缓存写入未设置 TTL，热点数据长期堆积占满 maxmemory，淘汰策略为 noeviction，写入失败后请求全部回源
- 处置: 临时扩容 Redis；批量清理无 TTL 的 key；设置 allkeys-lru 并为业务 key 增加过期时间
- 复盘: 缓存规范缺少 TTL 强制要求；内存水位与淘汰次数未纳入监控
- 标签: redis,memory,cache,incident

## INC-010 基础镜像升级导致容器启动失败
- 时间: 2025-10-16
- 现象: 发布后容器反复重启，docker 显示退出码 127，日志报 executable file not found
- 根因: 基础镜像从 glibc 版本切换到 musl，启动脚本依赖的二进制不兼容，且镜像标签使用了 latest
- 处置: 回滚到上一版镜像；固定基础镜像版本与摘要；在 CI 中增加容器启动冒烟测试
- 复盘: 使用 latest 标签使构建不可复现；镜像升级未在预发验证启动链路
- 标签: container,docker,release,incident
